# Bedrock documentation

Start with [the quick start](../README.md#get-started), then choose a guide:

- [User guide](user-guide.md): write and organize notes, use shortcuts, import, export, and recover drafts.
- [Self-hosting and configuration](self-hosting.md): run a server locally or behind HTTPS, connect clients, back up, and upgrade.
- [Troubleshooting](troubleshooting.md): diagnose a failed connection or save without losing drafts.
- [Architecture](architecture.md): understand ownership of data, API boundaries, and the source tree.
- [Development](development.md): build, test, contribute, and package releases.
- [API reference](../API.md): integrate with the server directly.
- [Design language](../DESIGN.md): palette, typography, navigation, and responsive behavior.
- [Verification](../VERIFICATION.md): current evidence and checks still requiring a real device or Linux host.

Examples use `notes.example.org`; replace it with your own hostname. Never paste access keys, cookies, notebook exports, or private notes into a public issue.
