# Bedrock 0.4.1

Your notes. Solid ground. Bedrock is a self-hosted Markdown notebook powered by Rust and SQLite, with a shared web/PWA interface and native Windows/Android clients.

This first public release includes linked notes and backlinks, an Atlas graph, tags, search, daily notes, Markdown import/export, JSON backups, draft recovery, access-key sessions, and Docker/HTTPS deployment examples. The stone-and-forest interface uses original artwork.

## Finishing touches

- Keyboard shortcuts help, Escape panel dismissal, focus restoration, skip navigation, and accessible editor-mode state.
- Portable Markdown export filenames, including titles with Windows-reserved characters and names.
- Clear connection recovery and a retry action if the initial notebook load fails.
- A full documentation set, contribution/security guidance, CI checks, and issue templates.

## Downloads

| Asset | Use |
|---|---|
| `Bedrock-windows-server.zip` | Extract, run `Start-local.cmd`, open `http://127.0.0.1:4173` |
| `Bedrock-windows-desktop.zip` | Portable x64 native client; needs WebView2 and your server URL |
| `Bedrock-android-arm64-debug.apk` | ARM64 test APK for Android 7/API 24+ |
| `Bedrock-source.zip` | Complete source and documentation, including Linux source |
| `Bedrock-SHA256SUMS.txt` | SHA-256 checksums for the supplied artifacts |

Windows binaries are unsigned. The Android APK is debug-signed for sideload testing, with the same certificate as the previous local build; it is not a Play Store release. Linux DEB/AppImage packages are not supplied. The browser UI was exercised; native device UI was not automated. No production deployment or Docker Engine runtime test is claimed.

## Validation and upgrade

47 Rust tests, 15 JavaScript tests, Rust formatting/Clippy, and local documentation-link checks pass. The shared UI was checked at 320 and 390 px widths. APK signature, ZIP integrity, and 16 KB ZIP/ELF alignment were verified.

Existing Lattice notebooks keep their database path, UUID, schema, note content, native identity, and recovery format. Old configuration/header names remain accepted, and the updated client connects to a 0.3 server. Back up before upgrading and keep your original Compose project name to reuse its volume.

This is a personal/shared-key notebook with server-confirmed saves, not a multi-user or full offline synchronization system. Read the [documentation](https://github.com/Manicharan01/bedrock-notes/tree/main/docs) and [security boundaries](https://github.com/Manicharan01/bedrock-notes/blob/main/SECURITY.md) before exposing a server remotely.
